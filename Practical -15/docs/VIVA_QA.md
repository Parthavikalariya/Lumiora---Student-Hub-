# Practical 15 – easy viva questions & answers

**Q1. What is full-stack integration?** Combining frontend HTML/CSS/JS with PHP backend, database, login and all modules into one working website.

**Q2. Why use XAMPP?** It provides Apache web server, PHP and MySQL/MariaDB to run the site locally.

**Q3. What is RBAC?** Role-Based Access Control: the server permits admin functions only to accounts with the admin role.

**Q4. What is a PHP session?** A server-side way to keep authenticated identity between HTTP requests, tracked using a cookie.

**Q5. What does AJAX/Fetch do?** JavaScript makes API requests and updates part of a page without fully reloading it.

**Q6. Why JSON?** JSON is a simple structured data format shared by PHP APIs and JavaScript.

**Q7. What is SQL injection prevention?** Use prepared statements and bound parameters instead of concatenating untrusted input into queries.

**Q8. What is CSRF?** An unwanted request made using a signed-in browser. A session-bound CSRF token helps reject forged writes.

**Q9. What is an audit log?** A database record of who performed an action, what changed and when.

**Q10. What is soft delete?** Marking a record archived/inactive instead of deleting its row permanently.

**Q11. What is a virtual host?** Apache configuration that maps a local domain name like `lumiora.local` to the project folder.

**Q12. Can GitHub Pages run PHP + MySQL?** No. It hosts static frontend files; the backend needs PHP/MySQL-compatible hosting.

**Q13. How are the dashboard counts produced?** SQL COUNT queries against user, student, event and registration tables.

**Q14. How did you test integration?** Open each module, exercise test CRUD records, check DevTools network requests, verify DB rows and roles, and record results in the test report.

**Q15. What is a Git commit?** A saved snapshot of tracked source changes. A GitHub push uploads commits to a remote repository.
